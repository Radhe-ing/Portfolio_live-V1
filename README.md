# Rabi Sankar Panda — Portfolio V1

A cinematic engineering portfolio built using pure HTML, CSS, and Vanilla JavaScript.

- warm cinematic motion
- horizontal scene transitions
- minimal interaction
- systems-inspired visual language
- engineering-focused presentation
